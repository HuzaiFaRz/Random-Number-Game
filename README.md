# 🎮 Random Number Game

> An interactive grid-based number finding game with dynamic number generation and timer functionality.

🔗 Live Demo: https://huzaifarandomnum.netlify.app/  
🔗 GitHub Repo: https://github.com/HuzaiFaRz/Random-Number-Game  

---

## 📌 Project Overview

This project generates a grid of random numbers where users must find and click the target number within a time limit. After each correct selection, numbers regenerate dynamically.

---

## ✨ Features

- 100-box dynamic grid generation
- Random number assignment
- Target number display
- Real-time timer functionality
- Automatic number reshuffling after each correct click
- Responsive layout

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
